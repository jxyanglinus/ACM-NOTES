## 例题
### 描述

哈基米非常喜欢喝雨水，这天雨姐要为哈基米下一场大雨，哈基米为了这一天准备了很久……为了接雨水哈基米准备了 n 根柱子，每根柱子长度为 hi​ ，哈基米希望重新排列这些柱子来接足够多的雨水，如果哈基米喝不到 k 滴的雨水那么哈基米就会哈气，为了避免哈基米哈气，我们需要帮助哈基米重新排列这些柱子使哈基米至少能够喝到 k 滴的雨水。举个例子，如果哈基米有高度分别为 (1,5,2,1,4) 的五根柱子，它可以这样排列柱子,柱子不能上下叠放。

```
 *
 *  *
 *  *
 ** *
*****
```

这样会接住 5r 雨滴（r 代表 1 个单位的雨滴）。为了方便表述，我们定义 r 为雨滴的单位。

```
 *
 *RR*
 *RR*
 **R*
*****
```

当然了，它也可以这样摆放柱子，这样可以接住 6r 雨滴。

```
 *
 *RR*
 *RR*
**RR*
*****
```

### 输入描述

第一行输入一个整数  T(1≤T≤100) ，表示样例个数。  
对于每一个样例: 第一行两个整数 n(1≤n≤105)，k (1≤k≤109)  
第二行 n 个整数 h1​,h2​,...,hn​ (1≤hi​≤105)

### 输出描述

对于每个测试用例，如果重新排列后可以使哈基米不哈气，则输出 “YES”，否则输出 “NO”。

### 用例输入 1 

```
2
5 7
1 5 2 1 4
6 100
1 1 4 5 1 4
```

### 用例输出 1 

```
YES
NO
```

### 提示

YES，NO严格大小写

柱子只能竖直放置，必须相邻

## 思路：

- **经典接雨水问题**。给定柱子可以任意排列，要让接水量最大，应把**最高**和**次高**的柱子放在两端，其余柱子放在中间。
- ![[接雨水问题示意图.png]]
- 这样中间所有柱子的高度都不超过次高，水面高度由两端较矮者决定，即 `mx2`。
- 最大接水量为（画图，借助容斥原理理解）：
    
    $$ans=(n−1)×mx2−sum+mx1$$
    
    其中 `mx1` 是最大值，`mx2` 是次大值，`sum` 是所有柱子高度之和。
    
- 若 `n <= 2`，无法形成凹槽，接水量为 `0`。
    
- 最后比较 `ans >= k` 输出 `YES`，否则输出 `NO`。
## 代码
```cpp
#include <bits/stdc++.h>  
using namespace std;  
  
const int maxn = 1e5 + 5;  
int n, k;  
  
int main() {  
    int T;  
    scanf("%d", &T);  
    while (T--) {  
        scanf("%d%d", &n, &k);  
        int total = 0, maxv = 0, maxsec = 0;  
        int len;  
        for (int i = 1; i <= n; i++) {  
            scanf("%d", &len);  
            total += len;  
            if (len > maxv) {  
                maxsec = maxv;  
                maxv = len;  
            } else if (len > maxsec) {  
                maxsec = len;  
            }  
        }  
        int ans = 0;  
        if (n >= 3) {  
            ans = (n - 1) * maxsec - total + maxv;  
        }  
        if (ans >= k) printf("YES\n");  
        else printf("NO\n");  
    }  
    return 0;  
}
```
