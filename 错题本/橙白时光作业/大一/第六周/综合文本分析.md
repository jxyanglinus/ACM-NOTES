# 题目
## 描述

读取一整行文本，只去掉行末换行，依次计算字符总数、单词个数、英文字母个数、数字个数，并找出最长单词。单词是连续的非普通空格字符形成的最大片段，数字和标点也是单词的一部分。字符总数包含所有空格；字母只包括 A～Z、a～z，数字只包括 0～9。最长单词按原始字符完整输出；多个单词并列最长时取最先出现的。若没有单词，最长单词为空串。

## 数据范围与约定

- 每行文本长度为 0～200，长度不包含行末的 LF 换行字符。
- 文本仅包含 ASCII 可打印字符，编码范围为 0x20～0x7E；其中允许普通空格，不包含制表符、回车、中文等字符。
- 空行合法。前导空格、尾随空格和连续空格均属于文本内容，读取时只去掉行末换行，不得自动修剪空格。
- 输入使用 LF 换行，每一行末尾均有一个 LF；本题每次运行只处理一组数据。
- 所有处理写在 main 函数中，不使用自定义函数。

每次运行只处理题目规定的一组数据，没有测试组数 T。数值输入的分隔方式及文本输入的空格保留规则，以输入格式为准；只输出题目要求的内容，不输出提示语。

输入描述

输入一行文本，长度不超过 200，允许为空行或全为空格。

输出描述

固定输出五行，依次为 n=字符总数、words=单词数、letters=字母数、digits=数字数、longest=最长单词。没有单词时第五行只输出 longest=，随后换行。

```

```

用例输出 1 

```
n=21
words=4
letters=14
digits=4
longest=language
```

## 正解代码
```cpp
#include <stdio.h>
#include <ctype.h>
#include <string.h>
#include <stdbool.h>

enum { maxn = 205 };
char str[maxn];
int n;

int word_count(const char *str, int len) {
	int cnt = 0;
	int pos = 0;
	while (pos < len) {
		while (isspace(str[pos]) && pos < len) pos++;
		bool flag = false;
		while (!isspace(str[pos]) && pos < len) pos++, flag = true;
		if (flag) cnt++;
	}
	return cnt;
}

int letter_count(const char *str, int len) {
	int cnt = 0;
	for (int i = 0; i < len; i++) {
		if (isalpha(str[i])) cnt++;
	}
	return cnt;
}

int digit_count(const char *str, int len) {
	int cnt = 0;
	for (int i = 0; i < len; i++) {
		if (isdigit(str[i])) cnt++;
	}
	return cnt;
}

void get_longest(const char *str, int len) {
	int pos = 0;
	int maxv = 0;
	int ans_start = 0, ans_tail = 0;
	while (pos < len) {
		while (isspace(str[pos]) && pos < len) pos++;
		int cur_len = 0, start = pos, tail = pos;
		while (!isspace(str[pos]) && pos < len) pos++, cur_len++, tail++;
		if (maxv < cur_len) {
			maxv = cur_len;
			ans_start = start, ans_tail = tail;
		}
	}
	printf("longest=");
	if (ans_start == ans_tail) {
		printf("\n");
		return;
	}
	for (int i = ans_start; i < ans_tail; i++) { // 原先出问题的地方
		putchar(str[i]);
	}
	printf("\n");
}

int main() {
	if (fgets(str, sizeof(str), stdin) != NULL) {
		str[strcspn(str, "\n")] = '\0';
		n = strlen(str);
	}
	// 1
	printf("n=%d\n", n);
	// 2
	printf("words=%d\n", word_count(str, n));
	// 3
	printf("letters=%d\n", letter_count(str, n));
	// 4
	printf("digits=%d\n", digit_count(str, n));
	// 5
	get_longest(str, n);
	return 0;
}
```

### 原先出错的代码（局部）
```cpp
// 错误版本
for (int i = ans_start; i <= ans_tail; i++) {
	putchar(str[i]);
}
```
```cpp
// 改正后
for (int i = ans_start; i < ans_tail; i++) { 
	putchar(str[i]);
}
```
- 分析：原本竞赛习惯了遍历从 $1$ 开始，遍历 $[1, n]$，现在这里是从 $0$ 开始，遍历 $[0, n)$，习惯上没有转换过来。
- 反映到本题目代码就是：`ans_start` 确实是答案（最长单词）起点，但是 `ans_tail` 是答案终点的下一个位置，所以遍历打印的时候应当遍历 `[ans_start, ans_tail)`。
- **为什么一直发现不了：因为单词是用空格隔开的，本题答案单词后面有一个空格，而多打印一个空格肉眼根本观察不出来，但是会一直爆 Presentation Error！**
